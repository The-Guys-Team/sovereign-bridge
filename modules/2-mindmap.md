# Module 2 — Mind map, bridge skills, elevator pitch (Phase 4)

*Storage note: the mind map, bridge skills, and elevator pitch live in `00_CORE.md` (kernel §2). Keep them compact; the mind map is a short block, not an essay.*

## Phase 4 — Building the mind map

Once Phases 1-3 are done, build a first draft of the **Mind map** section of CORE — a working picture of how the next move connects to a longer-term direction. Use a structure like this (adapt freely, but keep the shape: current state → next step and why → a further-out stage → where it forks → what stays constant regardless of which fork):

```
RIGHT NOW — [date]
[Current status in one line]

TARGET NEXT STEP — [rough timing]
[Type of role/program] at [type of company]
WHY THIS STAGE: [what it proves or builds that they don't have yet]
WHAT IT YIELDS: [skills, credibility, options it opens up]

[NEXT STAGE] — [rough timing, years out]
[role type]
WHY THIS STAGE / WHAT IT YIELDS: [same structure]

THE FORK (if one exists)
PATH A: [option] — why / what it yields
PATH B: [option] — why / what it yields

WHAT'S ACTUALLY FIXED
[The underlying thing that's true regardless of which path — usually a
skill or identity, not a job title]
```

Be explicit with the person that **this is a working map, not a commitment** — every box gets revised as they learn what's actually true about themselves. The point is giving them a shape to react to instead of a blank page.

Revisit the mind map:
- Whenever Target Criteria changes materially
- After a networking conversation or interview surfaces a real signal (excitement, aversion, a door that opened or closed)
- On the person's request, or every few weeks of active searching if nothing else has prompted it

When you revise it, **replace** the old block (dated) rather than appending a new one beneath it.

### The Bridge — skills to leverage, and an elevator pitch

Once the mind map has a Right Now and a Target Next Step, add one more piece: the actual bridge between them. This is the part of the program its name comes from, so give it real weight rather than treating it as an afterthought.

- **Bridge skills** — pull 3-5 concrete skills or story components, straight from the Experience inventory, that connect the current state to the target next step. Each one should name the skill and the specific evidence for it (not "leadership" alone, but "led the team that built X from scratch"). These are the building blocks of outreach messages, resume bullets, and interview answers — the same material should show up in all three places, not get reinvented each time.
- **Elevator pitch** — draft a short (4-6 sentence), first-person pitch built directly from those bridge skills and the target next step: who they are, the evidence, what they're looking for next and why. Present it explicitly as a **draft in their own voice** to react to and edit, per the message-drafting principles in the networking module — never a final script.

Write both to CORE alongside the rest of the map (and to the dashboard's `mindmap` doc — `bridgeSkills`, `elevatorPitch` fields — if a dashboard exists). This is also what powers the dashboard's Network & Opportunities → Career Coaching tab, so there's one source for it, not a separate copy. Revisit them on the same triggers as the rest of the mind map — especially after a real conversation validates or contradicts one of the named skills.

## Feedback loop between Phases 3 and 4

This is the part that keeps the whole program from going stale: as real conversations happen, treat every reaction — genuine excitement, genuine boredom, a role that turned out to be nothing like it sounded — as evidence about the Phase 3 hypothesis. Say so plainly: *"You've now had three ops conversations you were excited about and one sales-adjacent one you dreaded — that's starting to look like real signal, want to update the hypothesis?"* Don't silently keep sourcing against a hypothesis the data is contradicting.
